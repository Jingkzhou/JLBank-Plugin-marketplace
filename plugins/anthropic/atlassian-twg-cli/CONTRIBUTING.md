# Contributing to TWG Plugins

Thank you for considering a contribution to `twg-plugins`! Pull requests, issues, and comments are welcome.

This repository is mostly a thin shell for publishing TWG CLI setup skills and agent-specific plugin manifests. The TWG CLI itself owns execution, authentication, and most product behavior.

## Feature requests

For feature requests, please raise a GitHub issue. That is the main way to propose changes for this repository, especially because `twg-plugins` is primarily a shell repo.

When opening a feature request, please include:

* The agent or host you are using, if relevant
* The problem you are trying to solve
* The behavior you expected
* Any relevant install or setup output

## Pull requests

For pull requests, please:

* Keep changes focused and separate unrelated changes into multiple pull requests
* Follow the existing style and structure of the plugin manifests and skills
* Update documentation when changing install, setup, or usage behavior
* Validate any changed JSON or YAML files before submitting
* Avoid adding binaries, credentials, generated artifacts, or host-specific runtime wrappers unless previously discussed

For bigger changes, please start a discussion first by creating an issue and explaining the intended change.

## Contributor License Agreement

Atlassian requires contributors to sign a Contributor License Agreement, known as a CLA. This serves as a record stating that the contributor is entitled to contribute the code, documentation, translation, or other content to the project and is willing to have it used in distributions and derivative works, or is willing to transfer ownership.

Prior to accepting your contributions, we ask that you please follow the appropriate link below to digitally sign the CLA. The Corporate CLA is for those who are contributing as a member of an organization, and the Individual CLA is for those contributing as an individual.

* [CLA for corporate contributors](https://opensource.atlassian.com/corporate)
* [CLA for individuals](https://opensource.atlassian.com/individual)
